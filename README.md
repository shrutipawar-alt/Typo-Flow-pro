# ⌨️ TypeFlow Pro

A modern and professional typing speed tester built using HTML, CSS, and JavaScript. TypeFlow Pro helps users improve their typing speed, accuracy, and consistency through real-time performance tracking and an interactive user interface.

---

## 🚀 Live Features

### 🎯 Typing Test
- Real-time typing challenge
- Random paragraph generation
- Easy, Medium, and Hard difficulty levels
- Instant typing feedback

### ⚡ Performance Tracking
- Words Per Minute (WPM)
- Accuracy Percentage
- Error Counter
- Typed Characters Counter

### ⏱️ Smart Timer
- 30 Seconds
- 60 Seconds
- 120 Seconds
- Circular Progress Indicator

### 🏆 Results System
- Detailed performance summary
- Result popup modal
- Best performance tracking

### 📊 Leaderboard
- Local storage based leaderboard
- Stores recent test results
- Performance history

### 🎨 Modern UI
- Glassmorphism design
- Animated background effects
- Responsive layout
- Dark theme support
- Smooth animations

## 📈 Performance Metrics

The application calculates:

### WPM Formula

```text
WPM = (Correct Characters / 5) ÷ Time in Minutes
```

### Accuracy Formula

```text
Accuracy = (Correct Characters ÷ Total Typed Characters) × 100
```
